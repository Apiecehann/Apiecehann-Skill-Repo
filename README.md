# Apiecehann Skill Repo

[Research Figure Skill](research-figure-skill/README.md)：用统一脚本与可调整的示例配置生成科研图件。当前由一个渲染器支持六套柱形图版式，包括多系列分组、横向百分比和增益箭头，包含数据、配置及 PNG/PDF/SVG 成图。

![Grouped bar example](research-figure-skill/quantitative-plots/grouped-bar/examples/cue-comparison/figure.png)

从 [安装与运行说明](research-figure-skill/README.md) 开始；从 [图型目录](research-figure-skill/quantitative-plots/grouped-bar/README.md) 选择示例。新增 [风格、配色与字体索引](research-figure-skill/quantitative-plots/grouped-bar/examples/style-guide/README.md)：3 套风格、3 种布局、5 套色板、3 套字体，含独立填充／描边透明度与 [五页成图对照 PDF](research-figure-skill/quantitative-plots/grouped-bar/examples/style-guide/catalog.pdf)。
